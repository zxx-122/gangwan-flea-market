# 校园好物市场（小程序端）

"港湾跳蚤市场"的微信小程序端，与网页版共用同一后端（https://www.zxczhuanshu.xyz/api）和同一账号体系。

## 功能清单

- 登录 / 注册（账号密码，与网页版账号互通，注册即送 1000 体验金）
- 首页：分类筛选、最新/最热/价格排序、平台公告横幅、下拉刷新、触底加载
- 商品详情：图片轮播预览、库存显示、宝贝评价列表、卖家评分、收藏、联系卖家、举报
- 下单购买：收货信息填写、余额预校验（余额不足引导去充值）
- 发布 / 编辑商品：图片上传（wx.uploadFile，最多9张）、库存、成色、类目成交参考价
- 我买到的：确认收货 / 取消订单 / 评价卖家 / 物流单号复制
- 我卖出的：收货信息查看、填写物流发货、评价买家
- 钱包：余额总览、充值（演示环境模拟到账）、资金流水
- 我的收藏 / 浏览历史（本地存储，可清空）
- 消息会话（未读角标）、聊天（快捷短语、3秒轮询、自动滚底）
- 我的：资料统计、修改密码、退出登录

## 使用方法

1. 用微信开发者工具「导入项目」，目录选择本文件夹（`小程序-校园好物市场`），AppID 使用测试号（`project.config.json` 中默认 `touristappid`，正式使用时替换为自己的 AppID）。
2. 详情 → 本地设置 → 勾选「不校验合法域名」（开发阶段）。正式发布前需在微信公众平台配置 request/uploadFile 合法域名：`https://www.zxczhuanshu.xyz`。
3. 编译即可预览。账号与网页版互通，可直接用网页版注册的账号登录。

## 微信登录（预留）

当前版本使用账号密码登录，与网页版一致。如需接入微信一键登录：

1. 在微信公众平台获取 AppSecret；
2. 后端新增 `POST /api/auth/wx-login` 接口：接收小程序 `wx.login()` 的 code，调用微信 `jscode2session` 换取 openid，按 openid 查找/创建用户并签发本系统的 JWT；
3. `pages/login/login.js` 中调用 `wx.login()` 获取 code 后请求该接口即可。

## 注意事项

- WXML 内不支持方法调用与可选链（`?.`），所有格式化在 JS 中预处理；
- `wx:else` 必须紧邻 `wx:if`；
- 演示环境短信验证码不适用于小程序端，注册使用账号密码即可；
- 管理后台仅提供网页版（admin.html），小程序端不包含管理功能。
